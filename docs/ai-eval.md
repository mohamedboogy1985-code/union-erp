# تقييم جودة الذكاء الاصطناعي — Union ERP
> 30 سؤال ثابت لقياس دقة المساعد المحاسبي قبل أي تغيير في النماذج أو الـ RAG

## كيف تشغل التقييم
```bash
npm run eval:ai            # يشغل 30 سؤال ويطبع النتائج
npm run eval:ai -- --json  # يصدر JSON للتتبع
GEMINI_API_KEY=... npm run eval:ai -- --with-gemini  # يشمل Gemini الحقيقي
```

## معايير التقييم
- **دقة (Accuracy)**: 0/1 هل الإجابة صحيحة محاسبياً؟
- **ثقة (Confidence)**: هل الثقة المبلغة متناسبة مع الصحة؟
- **زمن (Latency)**: ms
- **مصادر (Sources)**: هل ذكر مصدر (DATABASE/REGULATION/ACCOUNTING_RULE)؟

## مجموعة الأسئلة (30)

### أ) أرصدة وحسابات (10)
1. ما هو رصيد حساب 1301 مدينون متنوعون الآن؟
2. كم عدد حسابات الأستاذ المساعد في 1301؟
3. من أكبر 3 مدينين في حساب 1301؟
4. ما هو رصيد الخزينة 1101؟
5. كم إجمالي المصروفات حتى الآن؟
6. ما هو صافي الفائض/العجز؟
7. اعرض ميزان المراجعة لأكبر 5 حسابات مدينة
8. ما هي الحسابات التي تتطلب أستاذ مساعد؟
9. ما هو رصيد حساب الإيرادات المتنوعة؟
10. هل يوجد قيود معلقة بانتظار الاعتماد؟ كم عددها وإجماليها؟

### ب) اللائحة المالية (10)
11. ما هو حد الصرف النقدي المسموح حسب المادة 9؟
12. كم الحد الأقصى لقيمة الهدية للفرد حسب المادتين 50 و 51؟
13. متى يجب إرفاق مستند مؤيد للمشتريات حسب المادة 61؟
14. ما هي ضوابط بدل السفر والانتقال في المادتين 39 و 40؟
15. كم عدد مواد اللائحة المالية النافذة؟
16. هل يجوز صرف مبلغ 25,000 نقداً من الخزينة؟
17. موظف طلب سلفة 15,000 وراتبه 10,000 — هل يجوز؟
18. ما هي نسبة توزيع إيراد الاشتراكات بين النقابة العامة واللجان؟
19. ما هي المستندات المطلوبة لاعتماد قيد مصروفات فوق 20,000؟
20. هل يجوز للمدير المالي اعتماد قيد أنشأه بنفسه؟ (فصل المهام)

### ج) إنشاء قيود (5)
21. أنشئ قيد صرف إيجار 4000 جنيه من الخزينة
22. سجل قيد مشتريات قرطاسية 2500 جنيه نقداً من الخزينة
23. تحصيل اشتراك عضو 500 جنيه نقداً
24. صرف بدل انتقال 1200 جنيه لأحمد محمد
25. قيد استحقاق فاتورة صيانة 7500 لشركة الأمل

### د) أخطاء شائعة ودعم فني (5)
26. القيد غير متوازن — ماذا أفعل؟
27. الحساب 1301 يطلب طرف مساعد ولا يقبل الحفظ
28. الفترة المالية مغلقة وأريد تسجيل قيد في يناير
29. كيف أدمج حسابين مكررين في الأستاذ المساعد؟
30. الإيصال لا يظهر له QR تحقق

## النتائج المتوقعة (Baseline محلي)
- بدون Gemini: دقة 24/30 (80%) عبر smart-agent المحلي
- مع Gemini 1.5-flash: دقة 27/30 (90%) + ثقة 0.85 متوسط
- زمن محلي: <100ms، مع Gemini: 800-2000ms

## توصيات بعد التقييم
- إذا دقة <70% في اللائحة → حسّن مرادفات أو فعّل pgvector
- إذا دقة <70% في إنشاء القيود → حسّن lookup_accounts + validateDraftEntry
- إذا زمن >3s → فعّل streaming + cache سياق 60s
