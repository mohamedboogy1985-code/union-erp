# فصل البوابات — كل بوابة بشاشتها وبياناتها

> **التاريخ:** 2026-08-31
> **المشكلة:** الشريط الجانبي كان ثابتاً يعرض كل الشاشات في كل البوابات، والبيانات كانت مشتركة (org-general) حتى عند تغيير البوابة.

## ما تم إصلاحه

1. **البنية:** أُنشئ `src/config/portals.ts` كمصدر مركزي لتعريف البوابات وشاشاتها وكيانها الافتراضي.
   - `syndicate` → `org-general` → شاشة البداية `dashboard`
   - `training` → `org-training-center` → شاشة البداية `employees`
   - `committees` → `org-committees` → شاشة البداية `committees`

2. **الشريط الجانبي (Layout):** أصبح يُنشأ ديناميكياً من شاشات البوابة المختارة فقط، فلا تظهر شاشات بوابة أخرى.
   - أُضيف شريط علوي داخل القائمة يعرض اسم البوابة الحالية وكيان البيانات الخاص بها + زر «البوابات».

3. **اختيار البوابة (App + Gateways):**
   - عند اختيار بوابة تُضبط `organizationId` تلقائياً على كيان البوابة، وتُنقل إلى شاشة البداية الخاصة بها.
   - يُحفظ اختيار البوابة في `localStorage` (`union_active_portal`) فيبقى بعد إعادة التحميل.

4. **فصل البيانات في الخادم:**
   - أُضيفت منظمتان جديدتان في `server/db/store.ts`:
     - `org-training-center` — مركز تدريب النقابة العامة
     - `org-committees` — بوابة اللجان النقابية
   - كل التقارير/الارصدة/السياق تفلتر بـ `organizationId`، لذا تقرير ميزان بوابة النقابة يعرض أرقامها، وبوابة التدريب تبدأ منفصلة بلا خلط.

## التحقق

```bash
npm run build
npm test
```
