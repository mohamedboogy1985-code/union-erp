## 2) ميزة الصوت بالذكاء الاصطناعي — كانت لا تعمل، والآن تعمل

**سبب العطل:** المسار القديم كان يسجّل الصوت ثم يحوّله على الخادم عبر Gemini، وهو يحتاج `GEMINI_API_KEY`. بلا مفتاح ⇒ كل ضغطة ميكروفون تنتهي برسالة «تعذر تحويل الصوت». كذلك كانت الأخطاء تُعرض كتنبيه عابر بلا شرح للسبب.

**الحل الجديد (ثلاث طبقات بالترتيب، أول طبقة تعمل تُستخدم):**

| الطبقة | المحرّك | المطلوب | ملاحظة |
|---|---|---|---|
| 1 | التعرف **على الجهاز** داخل المتصفح | Chrome 138+ وحزمة اللغة | **يعمل بلا إنترنت وبلا مفتاح** |
| 2 | التعرف **المدمج بالمتصفح** (Chrome/Edge) | إنترنت فقط | **بلا مفتاح** (كان معطّلاً تماماً قبل الإصلاح) |
| 3 | تسجيل محلي + تحويل على الخادم | `GEMINI_API_KEY` | احتياطي للمتصفحات القديمة |

- الانتقال التلقائي بين الطبقات: لو فشلت طبقة بخطأ شبكة/خدمة ينتقل النظام للطبقة التالية بدل أن يقف.
- سطر حالة ظاهر داخل الودجت يشرح ما يجري: «بسمعك…»، «جارٍ التحويل…»، أو سبب الفشل بالتحديد (إذن ميكروفون • مفيش ميكروفون • محتاج إنترنت).
- تلميح زر الميكروفون يوضّح المحرّك المستخدم حالياً.
- نقطة تشخيص جديدة: `GET /api/ai/voice-status` ت  رجع `serverSttConfigured` و`demoMode` وقائمة المسارات وإرشاداً عملياً.
- **زر إملاء صوتي تجريبي** يظهر في وضع العرض (DEMO_MODE): ينفّذ مسار الصوت كاملاً (نص ← مسودة قيد ← مراجعة واعتماد) داخل بيئة بلا ميكروفون للعرض والتدريب.

## 4) حل مشكلة «تم رفض إذن الميكروفون» (تحديث)

**السبب الحقيقي:** المتصفح يرفض الميكروفون داخل أي **إطار مضمّن (iframe)** — ونافذة المعاينة إطار مضمّن، فالرفض يحدث قبل وصول الطلب للتطبيق أصلاً.

**الحل المُنفَّذ:**

| الإجراء | التفصيل |
|---|---|
| كشف تلقائي للسياق | عند فتح الودجت: `window.self !== window.top` ⇒ تظهر لوحة حل فوراً بلا انتظار ضغطة |
| زر **افتح في نافذة مستقلة** | يفتح البرنامج في تاب مستقل (`window.open`) — هناك يُسمح بالميكروفون بعد الضغط على «سماح» |
| تشخيص الإذن | إن كان الإذن مرفوضاً في تاب مستقل تظهر خطوات فتح قفل العنوان واختيار «الميكروفون: سماح» |
| **الإملاء النصي (نفس المسار)** | زر دائم بجانب الميكروفون: تكتب الإملاء بنفس صيغة كلامك ⇒ `parse` ⇒ **حفظ مسودة قيد** ⇒ زر «اعتماد وترحيل» — لا ترحيل بلا اعتمادك |
| ترويسة `Permissions-Policy` | `microphone=(self), camera=(self)` من الخادم (تكفي عند التشغيل المستقل/إلكترون) |
| لا فشل صامت | كل سبب فشل يظهر نصاً واضحاً داخل الودجت (إطار • إذن مرفوض • غير مدعوم) |

**إصلاح تقني مصاحب:** `/api/voice-journal/parse` يُرجع **تحليلاً فقط بلا حفظ**؛ فأصبح المسار في الواجهة: `parse` ثم `save` (POST /drafts) ثم `approve` — قبل الإصلاح كان الاعتماد يفشل بـ 400 «المسودة غير موجودة».

**أدلة:** `scripts/ui-voice-nav-check.mjs` = **17 ناجح / 0 فاشل**، ومنها: كشف الإطار + زر النافذة المستقلة (تاب فعلي) + الإملاء النصي يُنتج مسودة + اعتمادها ينتج قيداً مرحّلاً. لقطات: `assistant-shots/15-حل-حجب-الميكروفون-داخل-المعاينة.png` • `16-الإملاء-النصي-مسودة-قيد.png`.

## 5) الرد الصوت  : الذكاء الاصطناعي بقى يرد عليك بالصوت (تحديث)

**المطلوب:** المساعد لا يكتب الرد فقط، بل **ينطقه** — وتم كذلك نقل أيقونة المساعد العام ولوحته إلى **يمين** الواجهة.

| البند | الت  صيل |
|---|---|
| محرّك النطق | `SpeechSynthesis` المدمج في المتصفح/الجهاز — **بلا مفتاح وبلا إنترنت**، مع اختيار صوت عربي (`ar-EG` ← `ar-SA` ← أي صوت عربي متاح) |
| متى يرد صوتياً | كل رد من الودجت: أوامر مباشرة • مسودة بانتظار الاعتماد • نتيجة «نفّذ واعتمد ورحّل» • مسار الإملاء النصي • **وبعد الإملاء الصوتي يُشغَّل النطق تلقائياً** ⇒ محادثة صوتية كاملة (تتكلم ⇒ يتكلم) |
| تحكّم المستخدم | زر **تفعيل/إيقاف الرد الصوتي** في ترويسة الودجت (مفعّل افتراضياً) • زر **إيقاف القراءة** يظهر أثناء النطق • زر **«اسمع الرد»** أسفل كل رد لإعادة سماعه |
| لو مفيش صوت عربي | سطر `data-assistant-tts-note` يظهر بإرشاد عملي (ويندوز: الإعدادات ← الوقت واللغة ← الكلام ← إضافة صوت عربي) بدل الصمت |
| نقطة تشخيص | `GET /api/ai/tts-status` تشرح أن النطق من المتصفح (بلا مفتاح) وما البدائل لو الصوت غير متاح |
| مكان الأيقونة | الأيقونة `fixed right-5 bottom-5` واللوحة `right-3 bottom-3` (يمين الواجهة كما طُلبت) |
| مساعد اللوائح لا يختفي | لوحة المساعد العام على اليمين، ولوحة «محاسبك» على اليسار؛ فمساعد اللوائح ينزاح تلقائياً (`right-[33rem]`) ليظل ظاهراً وقابلاً للضغط أثناء فتح لوحة المساعد العام |

**سبب رسالة «تنسيق صوتي غير صالح (dataUrl)» وحلها:** المسجل كان يرسل حمولة فارغة/بلا `base64,`، ومسار `/stt` القديم كان يرفض أي نص بلا ترويسة `data:` فيرد «تنسيق غير صالح».

| المسار الجديد | السلوك |
|---|---|
| المدخلات المقبولة | `dataUrl` أو `audioDataUrl` أو `audio` أو `base64` خام + `mimeType` اختياري |
| حمولة فاضية | `400 STT_EMPTY_PAYLOAD` برسالة: «اضغط الميكروفون مرة للبدء ومرة للتوقف… أو استخدم الإملاء النصي» |
| تحويل على الخادم بلا مفتاح | `503 STT_KEY_MISSING` مع إرشاد استخدام التعرف بالمتصفح — **لا رسالة تنسيق** |
| فشل التحويل | `422 STT_FAILED` بسبب واضح |
| حماية مبكرة في الواجهة | `src/utils/voiceCapture.ts` يتحقق من وجود `base64,` قبل الإرسال ويرسل `mimeType` معه |

**أدلة:** `scripts/ui-voice-reply-check.mjs` = **12 ناجح / 0 فاشل**، ومنها: الأيقونة تبعد 20px عن اليمين واللوحة 12px • النطق يعمل بالصوت العربي المختار • «اسمع الرد» يعيد القراءة • الإيقاف يعمل • سطر الإرشاد يظهر عند غياب صوت عربي • الفحوص كلها تمر بلا أخطاء JavaScript. لقطة: `assistant-shots/17-المساعد-على-اليمين-ورد-صوتي.png`.

## 7) النص المنطوق: أرقام بالحروف • تشكيل • جمل قصيرة (تحديث)

المساعد بقى **يجهّز الرد للنطق** قبل ما ينطقه، فمحرك الصوت مايقابلش أرقاماً ولا رموزاً ولا جمل طويلة.

| القاعدة | التنفيذ |
|---|---|
| كل الأرقام كلمات عربية | المبالغ (`5,000.00 ج.م` ← «خمسةِ آلافِ جنيهٍ») • النسب (`14%` ← «أربعة عشر بالمائة») • التواريخ (`2026-09-20` ← «يوم عشرين من شهر سبتمبر سنة ألفين وستة وعشرين») • الكميات (`76 عاملاً` ← «ستة وسبعون عاملاً») • المستندات (`INV-2026-0052` ← «فاتورة ألفين وستة وعشرين رقم اثنان وخمسون») • **أكواد الحسابات تُقرأ رقماً رقماً** (`5007` ← «خمسة صفر صفر سبعة») • السالب («سالب») • المدى (`100-200` ← «من مئة إلى مئتين») |
| التشكيل | تشكيل الكلمات الحسّاسة (الهمزات والشدّات: «إنشاءُ • مُعلَّقةٌ • مُرحَّلٌ • مسؤولة») + كسرة الجر تلقائياً بعد حروف الجر («من بياناتِ • على راتبِ • في الشهرِ») — يتوقف عند محرك الصوت فلا يقرأ الكلمة غلطاً |
| التنفّس | فواصل ونقاط واضحة، تقسيم أي جملة طويلة إلى جمل قصيرة (حد 110 حرفاً) |
| بلا رموز | إزالة القوائم والنجوم والأقواس والرموز التعبيرية، و«×» ← «في»، «=» ← «يساوي»، «%» ← «بالمائة»، «بـ» ← «بقيمةِ»، والشرطة → وقفة |
| البند الناقص | «فاصلة صفر صفر» اتشالت: الكسور الصفرية تتقرأ «خمسون ألفاً جنيه» بلا حشو |

**الملفات:** `src/utils/speechText.ts` (المحرّك) • مربوط في: ودجت المساعد العام • مساعد القيود (`JournalAiAssistant`) • شاشة المساعد الذكي • محادثة المحاسبة • عارض قيود 2024 • صفحة البوابات • `speakArabic` • مساعد «محاسبك».

**ملاحظة مهمة:** النص **المكتوب على الشاشة** يبقى كما هو (بالأرقام والجداول) لأن المحاسب يقرأ الأرقام؛ التحويل يخص **النطق** فقط. ولو محتاج تقسيم صوتي مختلف، الاتجاه الواحد للتعديل هو `toSpokenArabic` في `src/utils/speechText.ts`.
