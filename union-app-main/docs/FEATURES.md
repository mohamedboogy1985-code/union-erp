# دليل الميزات — Union ERP

> محدّث وفق ما نُفذ من خطة `docs/IMPROVEMENTS.md`.

## الميزات الأساسية

### المحرك المحاسبي
- دليل حسابات هرمي متوافق مع الطبيعة النقابية مع منع القيد على الحسابات التجميعية.
- قيود مزدوجة متوازنة إجبارياً (فارق أقل من قرش يُرفض).
- **أستاذ مساعد إلزامي لحساب 1301** (مدينون متنوعون) مع تطبيع الأسماء العربية ومنع التكرار والدمج الذكي.
- دورة اعتماد كاملة: مسودة → مقدّم → معتمد → مرحّل، مع قواعد فصل المهام (SoD).
- قيود عكسية متوازنة تلقائياً مع سبب الإلغاء.
- أقفال الفترات المالية وإعادة الفتح المضبوطة (Special Reopen).

### التحصيل والإيصالات
- إيصالات مختومة SHA-256 مع رمز تحقق QR عام.
- محرك توزيع الإيرادات بقواعد نِسَب تلزم 100% (50/30/20 للاشتراكات مثلاً).

### شئون العاملين والتأمينات (استكمال وحدة شئون العاملين)
- **قاعدة عاملين حقيقية من «استمارة 2 تأمينات»** (76 عاملاً): الأجر الشامل، الأجر التأميني، حصص النقابة والعامل وفق الاستمارة مقابل المستقطع فعلياً.
- **كشف فجوة تحصيل حصة النقابة**: مقارنة تلقائية لكل عامل بين ما تقره استمارة 2 وما خُصم فعلياً (إجمالي الفجوة الفعلي المكتشف: 16,373.56 ج.م).
- **الشئون الإدارية**: إجازات سنوية / مرضية / أذونات / إنذارات / خصومات / مكافآت بدورة اعتماد (معلق → معتمد/مرفوض).
- **سلف العاملين**: صرف مجدول بأقساط شهرية، سداد أقساط (نقدي/تحويل/خصم من المرتب)، حارس منع تجاوز المتبقي، وإقفال تلقائي عند السداد الكامل.
- كل العمليات ضمن RBAC بصلاحية `hr:manage` ومسجلة في سجل التدقيق المترابط (Hash-Chain).

## الأمان (IMPROVEMENTS 5)

- رؤوس أمان HTTP + حد معدل الطلبات لكل IP.
- دخول JWT (HS256) مع تتبع محاولات فاشلة و**قفل تلقائي 5 محاولات/15 دقيقة**.
- **تحقق ثنائي TOTP** متوافق Google Authenticator (السر مشفر AES-256-GCM).
- تشفير البيانات الحساسة (أرقام قومية مُقنعة + مفاتيح HMAC).
- **سجل تدقيق شامل**: كل طلب API يوثق (IP/UA/مدة/حالة) والعمليات الكتابية تدخل سلسلة Hash-Chain.

## لوحة التحكم الذكية (IMPROVEMENTS 6)

- ملخص أرصدة فوري (أصول/التزامات/إيرادات/مصروفات/نقدي/1301).
- إنذارات: قيود معلقة، OCR فاشل، قيود غير متوازنة، مدينون خطرون، تجاوزات موازنة، حسابات مقفولة.
- رسوم: اتجاه المصروفات شهرياً، الإيراد حسب الفئة، توزيع الحسابات.
- فحص إنذارات دوري يطلق إشعارات متعددة القنوات تلقائياً.

## الأداء والتكامل (IMPROVEMENTS 7/8)

- كاش طبقتين (Redis عند التوفر، وإلا ذاكرة TTL) مع إبطال عند كل كتابة.
- ترقيم صفحي اختياري للقوائم الكبيرة (`?page=&limit=&sortBy=&sortOrder=`).
- استيراد خارجي موحد (حسابات/أعضاء/1301/قيود) وتصدير تقارير JSON/CSV-Excel.
- إشعارات: داخل التطبيق + بريد + SMS (قنوات خارجية اختيارية عبر مفاتيح البيئة).

## قوالب القيود

قوالب جاهزة (صيانة/رواتب/اشتراكات/شهادات/انتقالات) تُطابق أوامر المستخدم نصياً وصوتياً ويمكن الإنشاء منها بنقرة، مع إمكانية إضافة قوالب جديدة.
