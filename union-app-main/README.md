تطبيق متقدم للإدارة المحاسبية مع دعم الذكاء الاصطناعي والمعالجة الرقمية للمستندات.

## المميزات الرئيسية

### 1️⃣ المساعد الذكي للرد التلقائي (Automated AI Support Agent)
- **الإجابة الفورية**: رد تلقائي على استفسارات الحسابات، القوانين واللوائح النقابية (قاعدة معرفة محاسبية مدمجة)
- **ربط قاعدة البيانات**: استعلام مباشر عن حالة القيود والأرصدة وآخر الإيصالات (`/api/ai/account-1301`)
- **حساب 1301 الذكي**: متابعة فورية لأرصدة الأستاذ المساعد
- **تصنيف الأسئلة تلقائياً** (NLP عربي مبسط) + **التعلم من تقييمات المستخدمين**

### 2️⃣ إدخال القيود بالصورة والملفات (Vision & OCR to Entry)
- **معالجة ذكية للصور**: معالجة مسبقة بـ sharp (تصحيح الاتجاه/تباين/وضوح)
- **استخراج تلقائي**: المبلغ والتاريخ والبيان ورقم الفاتورة والمورد والضريبة
- **ربط دليل الحسابات**: اقتراح الحسابات المناسبة بدرجات ثقة
- **قيد متوازن**: مسودة قيد مزدوج متكامل جاهز للاعتماد (مع فصل ضريبة القيمة المضافة)

### 3️⃣ إدخال القيود بالأوامر الصوتية (Voice-to-Journal)
- **تحليل صوتي لحظي**: التحدث المباشر باللغة العربية (لهجات ومترادفات وأرقام هندية وأعداد كلمات)
- **أمثلة**: "تسجيل قيد مصروفات صيانة بقيمة 1500 جنيه بشيك من بنك مصر"
- **توجيه محاسبي تلقائي**: تحويل الأوامر الصوتية إلى قيود موزونة + **تأكيد إجباري للقيود الكبيرة**

### 4️⃣ الأمان المتقدم (Security Hardening)
- دخول JWT + **قفل الحساب تلقائياً** بعد 5 محاولات فاشلة
- **تحقق ثنائي 2FA (TOTP)** متوافق مع Google Authenticator (سر مشفر AES-256-GCM)
- رؤوس أمان HTTP + حد معدل الطلبات + **سجل تدقيق شامل مترابط بالتشفير (Hash-Chain)**

### 5️⃣ لوحة تحكم ذكية وأداء
- ملخص أرصدة فوري + إنذارات ذكية (قيود معلقة/OCR فاشل/مدينون خاطرون) + رسوم بيانية
- **كاش طبقتين** (Redis/ذاكرة) + **ترقيم صفحي** للقوائم الكبيرة
- قوالب قيود ذكية + سجل التحديثات المحاسبية لكل حساب

### 6️⃣ شئون العاملين والتأمينات (استمارة 2)
- **قاعدة عاملين حقيقية (76 عاملاً)** من ملف «استمارة 2 تأمينات»: الأجر الشامل/التأميني وحصص النقابة والعامل
- **كشف فجوة تحصيل حصة النقابة** بين ما تقره الاستمارة والمستقطع فعلياً لكل عامل
- **الشئون الإدارية**: إجازات/مرضيات/أذونات/إنذارات/خصومات/مكافآت بدورة اعتماد كاملة
- **سلف العاملين**: صرف بأقساط شهرية + سداد (نقدي/بنكي/خصم من المرتب) + إقفال تلقائي عند التسوية

## المكدس التكنولوجي

- **Frontend**: TypeScript, React 19, Vite, Tailwind CSS
- **Backend**: Node.js, Express, TypeScript (tsx)
- **AI/ML**: Google Gemini API (مع بدائل محلية عند غياب المفتاح)
- **Database**: PostgreSQL (Drizzle ORM + مخطط Prisma مرجعي) — اختياري، يعمل النظام بذاكرة داخلية للعرض
- **Auth**: JWT (HS256) + TOTP 2FA + Rate Limiting + Audit Hash-Chain

## البدء السريع

### المتطلبات
- Node.js 18+
- npm 9+
- (اختياري) مفاتيح Gemini، PostgreSQL، Redis

### التثبيت

```bash
git clone https://github.com/mohamedboogy1985-code/union-app.git
cd union-app
npm install
cp .env.example .env
```

> 💡 النظام يعمل فوراً دون أي خدمة خارجية: بيانات العرض داخل الذاكرة
> والخدمات الذكية تتحول لبدائل محلية ذكية عند غياب المفاتيح.

### تشغيل التطبيق

```bash
npm run dev        # http://localhost:3000
npm test           # حزمة الاختبارات (8 محاسبية + 14 تحسينات)
```

### متغيرات البيئة

راجع `.env.example` للقائمة الكاملة. الأهم:

```env
GEMINI_API_KEY=your_gemini_key       # اختياري
JWT_SECRET=your_secret_key
MAX_FAILED_ATTEMPTS=5                # سياسة قفل الدخول
VOICE_CONFIRMATION_THRESHOLD=50000   # حد تأكيد القيود الصوتية
```
