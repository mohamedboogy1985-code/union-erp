```powershell

```

| العنوان | المحتوى |
|---|---|

| `http://localhost:3000/api/regulation` | محرك اللائحة الأصلي بعد التصحيح |

أوامر التحقق الثلاثة والفحوص الإضافية:

```powershell
npx tsc --noEmit -p tsconfig.statutory.json   # 0 خطأ في نطاق الوحدات المضافة
npx tsx scripts/verify-statutory-integration.ts   # 50/50 فحصاً
node scripts/live-integration-check.mjs           # 13/13 على خادم عامل
```

**مرحلة الإنفاذ:** الافتراضي `SHADOW` (ترصد المخالفة ولا تمنع — لا تعطيل لعملك اليومي). لتغييرها:

```powershell
$env:STATUTE_ENFORCEMENT_STAGE = "ENFORCE"; npm run dev
```

السلّم: `SHADOW` → `AUDIT` → `WARN` → `ENFORCE`. ويمكن الفحص لطلب واحد بلا تغيير الإعداد: `?stage=ENFORCE`.
